# References

Official sources for the Moodle XML format and related Moodle features.
When a question arises about XML elements, attributes, or Moodle behavior, consult these
instead of guessing. All links verified on 2026-08-19.

## Moodle XML format

- [Moodle XML format](https://docs.moodle.org/en/Moodle_XML_format) —
  the primary written specification: per-type XML elements, common elements
  (`name`, `questiontext`, `answer`, formats), CDATA usage, and examples.
  Start here for any question about the export format.
- [format.php (moodle/moodle, main branch)](https://github.com/moodle/moodle/blob/main/public/question/format/xml/format.php) —
  the importer/exporter source code, and the de facto specification where the wiki is silent.
  Note that since Moodle 5.1 the code lives under `public/`; on older stable branches
  (e.g. `MOODLE_405_STABLE`) the path is `question/format/xml/format.php`.
- [XML test fixtures (moodle/moodle)](https://github.com/moodle/moodle/tree/main/public/question/format/xml/tests/fixtures) —
  real XML files used by Moodle's own PHPUnit tests (`multichoice.xml`, `truefalse.xml`,
  `multianswer.xml`, nested categories, and more). Useful as golden references for our writer output.

## Question types and cloze

- [Question types](https://docs.moodle.org/en/Question_types) —
  the full list of standard types. Beyond what questionsafe supports today, Moodle ships
  matching, select missing words (gapselect), drag-and-drop variants, ordering, and the
  calculated family.
- [Embedded Answers (Cloze) question type](https://docs.moodle.org/en/Embedded_Answers_(Cloze)_question_type) —
  the cloze syntax: subquestion formats, weights, feedback, shuffling, case sensitivity.
  The reference for `Cloze` and the `.cloze()` embedding methods.

## Question bank and quiz composition

- [Question bank](https://docs.moodle.org/en/Question_bank) —
  how imported questions are organized and managed on the Moodle side.
- [Question categories](https://docs.moodle.org/en/Question_categories) —
  category nesting and context sharing; background for `Q.Category` and `Quiz.add_category`.
- [Import questions](https://docs.moodle.org/en/Import_questions) —
  the import workflow teachers use to load our XML output.
- [Random question type](https://docs.moodle.org/en/Random_question_type) —
  how quizzes draw random questions from a category (or tag filter). This is the Moodle-side
  mechanism that question groups generated by `MetaChoice` are designed to feed.

## Developer documentation

- [Questions API](https://moodledev.io/docs/5.0/apis/subsystems/question) —
  overview of Moodle's question engine and question bank internals.
- [Question type plugins](https://moodledev.io/docs/5.0/apis/plugintypes/qtype) —
  how question types are implemented; useful for understanding what data a type
  actually stores. Per-type source lives at `public/question/type/<name>/` in moodle/moodle.

## Design reference

- [R/exams](https://www.r-exams.org/) —
  the design inspiration. Its `exams2moodle` writer covers dynamic exercise generation for
  Moodle; questionsafe trades that generality for tighter integration with Moodle-native features.
